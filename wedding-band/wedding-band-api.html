Headless API guide

The panel on the right is the built-in Wedding Band UI, loaded from iJewel Drive by fileId. Every button below configures the same band through the headless controller - the API your own storefront UI would use.

Watch both respond together: the controller is the single source of truth, so the model and the built-in panel stay in step whichever one makes the change. That is what lets you build a completely custom interface on top of the same engine.

Each button is labelled with the exact call it makes, so anything here can be copied straight into your own code. Results and warnings appear at the bottom, and the live controller is available as window.wbb in the browser console.
