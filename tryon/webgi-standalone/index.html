Two files per model

  • A .glb — the ring itself.
  • A .json — the try-on placement for that ring, produced by the plugin's setup mode.

Load both, in that order. The JSON is what tells the plugin how big the ring is and where it sits on a finger.

Camera access needs an HTTPS origin. Opening this file straight from disk (file://) loads the model but blocks the camera.
